# TaskSphere

## Project Overview
TaskSphere is a full-stack web application developed as part of the SOFT806 CI/CD assignment. It serves as a task management system, designed to explore and implement continuous integration and continuous deployment pipelines, alongside modern software development practices.

## Technology Stack
- **Backend**: Django REST Framework (Python)
- **Frontend**: React.js (JavaScript)

## Setup Instructions

### Backend Setup
1. Navigate to the `backend/` directory.
2. Create and activate a Python virtual environment.
3. Install the necessary dependencies (to be added).
4. Run the Django development server.

### Frontend Setup
1. Navigate to the `frontend/` directory.
2. Install Node.js dependencies using `npm install` or `yarn install`.
3. Start the React development server using `npm run dev` or `npm start`.
