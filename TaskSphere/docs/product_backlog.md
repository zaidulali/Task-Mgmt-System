# TaskSphere Product Backlog

| Category | Priority | User Story |

| **Application** | High | As a user, I want to register so that I can use the app. |
| **Application** | High | As a user, I want to log in so that I can see my tasks. |
| **Application** | High | As a user, I want to create tasks so that I can track them. |
| **Application** | High | As a user, I want to view tasks so that I know what to do. |
| **Application** | Medium | As a user, I want to edit tasks so that I can update them. |
| **Application** | Medium | As a user, I want to delete tasks so that I can remove them. |
| **Application** | Low | As a user, I want to log out so that my account is secure. |
| **DevOps** | High | As a dev, I want a PR workflow so that code is reviewed. |
| **DevOps** | High | As a dev, I want env variables so that secrets are safe. |
| **DevOps** | High | As a dev, I want GitHub Actions so that testing is automated. |
| **DevOps** | Medium | As a dev, I want to Dockerize the backend so that it runs anywhere. |
| **DevOps** | Medium | As a dev, I want to Dockerize the frontend so that it runs anywhere. |
